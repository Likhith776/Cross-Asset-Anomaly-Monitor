Step 01 · Ingest

Keyless quotes

A composite feed pulls every instrument on a 30-minute cadence, primary keyless sources first, with retries and a carried-state fallback.

Step 02 · Features

Rolling state

Z-scores, EWMA residuals, realised volatility and pairwise correlation are rebuilt from history on every restart, so a cold start is never blind.

Step 03 · Detect

Four detectors

Univariate z-score spikes, isolation forest outliers, correlation breaks and a multivariate Mahalanobis check vote on the same window; regimes rescale the thresholds.

Step 04 · Publish

Static, always up

The run writes JSON and a static page to a published branch. GitHub Pages serves it, and every human label feeds the rolling precision metric.
